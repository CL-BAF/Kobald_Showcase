# Public Kobald Examples

This folder contains sanitised, invented examples that make Kobald's documented behaviour easier to inspect without access to the private development repository.

- [Offline evaluation cases](offline_eval_cases.json) — nine representative cases covering contradictions, insufficient evidence, provenance, fabricated references, duplicate material, invalid paths, cloud consent, human review and later evidence changing an earlier conclusion.
- [Demonstration transcript](demo_transcript.md) — a complete invented example showing Kobald reviewing conflicting evidence, requesting more information, updating its conclusion and leaving final approval with a human reviewer.

These files are public showcase material. They are not verbatim exports of the private automated test fixtures and do not replace the private automated test suite.

See also [Testing and Verification](../docs/TESTING.md).
